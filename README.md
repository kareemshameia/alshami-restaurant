# مطعم الشامي — Alshami Restaurant 🍕🍔🍹

موقع وتطبيق ويب حديث لمطعم الشامي في دير البلح، مبني بأحدث تقنيات الويب:
- **Next.js 16 (App Router)** & **React 19**
- **Tailwind CSS v4** بتصميم عصري وألوان الهوية الداكنة (Dark Ink, Forest, Copper, Neon)
- **Supabase Database & Storage**: قاعدة بيانات سحابية وتخزين للصور ومزامنة فورية (Realtime WebSockets)
- **لوحة تحكم إدارية ذكية (`/admin`)**: لإدارة الأصناف، تعديل الأسعار، إيقاف/تفعيل الوجبات، ورفع الصور مع شريط تقدم مباشر.

## المميزات
- 🍕 عجلة بيتزا تفاعلية دوارة
- ⚡ شريط كلمات متحرك لانهائي وسلس
- 🛒 سلة طلبات تفاعلية وطلب مباشر عبر واتساب
- 📱 تصميم متجاوب فائق الدقة للهواتف والشاشات الكبيرة
- 🔄 مزامنة حية كاملة بدون تحديث الصفحة

## التشغيل المحلي (Local Development)
```bash
pnpm install
pnpm dev
```
افتح المتصفح على: `http://localhost:3000`
لوحة الأدمن: `http://localhost:3000/admin` (رمز PIN الافتراضي: 1234)
